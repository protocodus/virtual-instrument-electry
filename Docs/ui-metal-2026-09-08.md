# Electry black-metal interface — 8 September 2026

The interface now uses a satin graphite chassis, platinum and ivory lettering,
black machined dials and ember-orange accents. Cut corners, a forward-raked
wordmark and the sharp E emblem give it the visual character of a heavy
instrument. Materials, symbols and lettering are drawn directly in JUCE; the
previous wood bitmap is no longer embedded in the plugin.

![Electry interface](screenshots/electry-standalone.png)

The editor is 1180 × 880, with more horizontal room and consistent gaps between
performance, tone, output and effects. The keyboard retains its 100-pixel
playing area. Tone controls remain larger than texture details. Section
symbols, pick-direction arrows and amp-waveform icons accompany readable
labels; active states also use an indicator bar, rather than color alone.

The subsequent [FX toggle and spacing pass](fx-toggle-2026-09-08.md) increases
the height to 904 and adds the padded FX ON/OFF control shown in the current
screenshot below the introduction.
The [keyboard groups and Performance pass](ui-keyboard-groups-2026-09-08.md)
adds the color legend, widens Performance and brings the current height to 910
after consolidating the key ranges into the legend.

Captions now spell out Pick Position, Pick Hardness, Body Resonance, Palm
Pressure, Pick Noise and Release Noise. String Ring controls sympathetic
strings, Pick Rate controls tremolo picking, and Mechanics controls incidental
hardware/fret sounds. Pedal Drive and Amp Drive distinguish the two gain
stages. Double replaces the compact 2X caption. Long detail captions use two
lines. Canonical host parameter names, IDs, values and bindings are retained.

Build and quality help now describe practical musical choices. Detailed
keyswitch instructions remain in hover help and the keyboard guide. Menus,
editable values, hover, selected and disabled states share the same palette.
Keyboard navigation retains the existing Tab/arrow/Space/Return behavior,
accessible names and parameter-specific double-click reset. A platinum focus
outline replaces JUCE's stock yellow outline.

The fretboard uses ebony, titanium fret wires, split-diamond inlays and
strings drawn with different gauges. Sounding string sections glow ember;
sympathetic motion remains distinct. Function keys have a charcoal bank,
while pitched keys retain the familiar light/dark piano pattern.

## Validation

The existing native processor/editor suite checks all 25 knobs, 36 logical
keyboard stops, control bounds, label/value accessibility, reset behavior,
exclusive selections, program synchronization, output modes, keyboard gestures
and fretboard interaction. The popup palette expectations and renamed-caption
checks were updated to the new design, retaining their contrast and behavior
requirements. Build-help checks now test the practical setup description.

The native arm64 VST3, AU, CLAP and Standalone targets build. Processor/editor,
VST3, CLAP and AU checks pass. PNGs were rendered from the actual JUCE editor at
1× and 2×, with an additional sounding-performance capture. The screenshot
export is opt-in through the existing `ELECTRY_EDITOR_SNAPSHOT` environment
variable; it now writes `-2x` and `-active` companions for visual review.

Reproduce the screenshots and checks with the configured native build:

```sh
cmake --build build-ui-20260908/native --target \
  ElectryPluginProcessorTests ElectryVST3ArtifactSmokeTests \
  ElectryAUArtifactSmokeTests ElectryCLAPArtifactSmokeTests Electry_Standalone \
  --parallel
ELECTRY_EDITOR_SNAPSHOT="$PWD/build-ui-20260908/final.png" \
  ctest --test-dir build-ui-20260908/native \
  -R 'PluginProcessor|VST3Artifact|CLAPArtifact|AUArtifact' --output-on-failure
```

Before, after, scaled and active captures plus local build/check logs remain
under `build-ui-20260908/`. This pass changes the UI; the existing sound and
parameter-state behavior are covered by the processor checks.
