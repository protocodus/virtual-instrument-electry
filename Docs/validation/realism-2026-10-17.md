## Measurements

The [machine-readable summary](realism-2026-10-17.json) retains exact final
dispersion summaries and native timing rows. The independent modal sweep has
864 static cases: the two lowest strings, frets 0/2/7/12/17/22, light/heavy
gauge, 25.5/27.625-inch scales, bends -2/0/+2 semitones, and host rates
44.1/48/96/96.001/192/384 kHz. It does not cover every string or every Build
anchor. It disables attack tension to isolate the static stiffness problem.

Across 12,960 upper partials, maximum phase-resonance error improves from
209.385 to 88.908 cents; median absolute error worsens from 2.313 to 3.459
cents. The isolated vertical loop includes the actual cubic read and loss-filter
phase. Those are real-axis phase resonances of a lossy loop, not complex
damped-pole estimates; horizontal detuning and polarisation coupling are
omitted. An independently compensated lossless version isolates
the allpass approximation itself.

Native timing uses 32 warmup and 512 measured iterations per workload at
48/96/384 kHz: a cold eight-string fret-12 chord event and an eight-string
moving bend with 256-frame callbacks. Candidate median cost rises 31–35% and
31–40%, respectively. At 96 kHz its largest moving callback is 29.567 ms;
the callback period is 2.667 ms. Earlier contended runs and final sequential
runs are retained. Neither a quiet process scan at the start nor a later
measurement explains away that wall-time result; thread CPU was not measured.
This is a native engine diagnostic, not a Reason or target-chip CPU result.

The mass audit contains 24 arithmetic rows for eight light-gauge strings at
25.5/27.625/28 inches. The engine suite checks 240 SI tension/impedance cells,
240 attack/stop cases and fifteen pressure pairs. Only the light wound
construction is identified by manufacturer data. The heavy gauge morph is
explicitly a geometric-similarity hypothesis; neither core diameter nor an
actual eight-string performance is fitted.

## Listening artifacts and reproduction

The working output is `build-realism-review/`, excluded from Git. It contains
four 13–14-second A/B pairs in `listen/`, an interactive `index.html`, a separate
`key.md`, source/build hashes, exact events, raw WAVs, constant gain trims and
`SHA256SUMS`. A is the unchanged baseline. B enables exactly one experimental
macro. Each mechanism has a dry and an otherwise identical Modern-amp pair.
The mass audition fixes the measured light gauges rather than presenting the
unmeasured heavy morph as data. Both letters use the same driver, score,
seed, rate and block size. Each pair is matched by one whole-file RMS gain per
take, with shared peak headroom; no time alignment, EQ or windowed gain is used.

The builder initially detected identical A/B output and rejected it. Investigation
found that `git apply` under a nested output directory inherited the outer
repository and silently skipped DSP paths. The builder now initializes the
archived source's own repository, and a regression test reproduces the exact
nesting. Corrected final builds contain the intended source hashes and
nonidentical audio. The failed and final logs are retained.

```sh
cmake -S . -B build-realism -DCMAKE_BUILD_TYPE=Release \
  -DELECTRY_BUILD_PLUGIN=OFF -DELECTRY_BUILD_UNIVERSAL=OFF
cmake --build build-realism --parallel 2
ctest --test-dir build-realism -L unit --output-on-failure
ctest --test-dir build-realism -L audio --output-on-failure

python3 Tools/AuditStringConstruction.py --output construction.json
python3 Tools/AuditDispersion.py --output modes-A.json
python3 Tools/AuditDispersion.py --modal-fit --output modes-B.json
python3 Tools/AuditDispersion.py --benchmark-only --output cpu-A.json
python3 Tools/AuditDispersion.py --benchmark-only --modal-fit --output cpu-B.json

python3 Tools/BuildRealismComparisons.py \
  --base 45e9a818b0924917aa2fb2b92e88b4a8d1fc7cfa \
  --spec build-realism-review/spec.json --output build-realism-review
```

The working specification lists candidate commit `2ef0e1b`, probes
`string-mass` and `dispersion`, sounds `dry`/`amp`, and respectively defines
`ELECTRY_REFERENCE_STRING_MASS=1` or `ELECTRY_MODAL_DISPERSION_FIT=1`.
The builder requires NumPy/SciPy for audio packaging; the small patch-regression
test needs only Python and Git.

Raw numerical reports, intermediate fitter attempts, source-download receipts
and failed/passing test logs remain in the working `evidence/` directory.
No listening verdict has been recorded. The research report ranks seven
directions and distinguishes immediate numerical work from mechanisms that
need registered physical measurements.
