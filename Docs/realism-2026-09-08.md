# Five contact realism changes — 8 September 2026

This pass concentrates on the two hands and the thick low strings. All five
changes run in the shipping DSP, including the plug-in, without new host
parameters. The waveguide, string tuning, amps and cabinet remain the basis of
the instrument. The implementations are physically motivated approximations;
this is not a completed blind realism study or a capture of a particular guitar.

## The five ideas

1. **String-dependent pick recoil.** A .098 low string and a plain treble
   string should not leave the pick at the same speed. The model now uses the
   string's live transverse impedance, `sqrt(tension × mass per length)`, for
   the slip part of the release. It preserves the hand's loading time and
   normalizes the actual sampled pulse area, so longer recoil does not become
   an extra velocity gain. Fretting leaves the string impedance unchanged;
   changing gauge, scale or tension can change it. Finger-only gestures bypass
   this plectrum model. The final impedance ratio is bounded to 0.75–2.60
   against default E2: the treble speedup was reduced during validation to
   preserve the original humbucker spectral guard, while E1's longer recoil
   was retained.
2. **Winding-aware pick scrape.** The existing scrape bandwidth now follows
   estimated winding spacing on each wound string, reusing the slide model's
   wrap-pitch geometry. An oblique edge crosses coarser ridges less frequently
   at the same speed. The established default E2 is the reference; plain
   strings and finger-only contacts bypass this mapping. It supplies a missing
   construction coordinate, not another random noise layer.
3. **Releases follow remaining vibration.** Previously Note Off generated a
   burst from the original attack velocity, even after a long Palm decay.
   Release amplitude now follows the square root of the current-to-peak
   displacement-energy ratio. Repicks re-anchor that peak, silence clears it,
   and cancelled notes remain silent. The Release Noise control still governs
   its level.
4. **Finger relaxation and damping-hand stops differ.** A fretted note can end
   when its finger relaxes; an open string requires a stopping hand. A planted
   palm also remains the dominant stop. Closure blends from the existing
   10 ms finger-contact scale to the existing 22 ms hand scale. Broad-hand
   contacts have a quieter, darker transient; the final 60 ms loop T60 stays
   fixed. The 0.35 amplitude and 0.50 bandwidth endpoint ratios are explicit
   voicing choices, not measured physical constants.
5. **Hammer-ons land at the fret.** An ascending legato hammer previously
   reused a fixed near-bridge excitation position. Its reflected excitation
   now originates at the actual destination fret on the source speaking
   length, including a partly completed preceding glide and live bend.
   An 8 mm finger pad replaces the plectrum-width contact for this gesture.
   Existing descending pull-off geometry retains its old-fret release point.

## Real-recording direction checks

Three publicly accessible CC0 eight-string recordings supplied independent
audio examples at F#1, C2 and F#2. We downloaded and measured their public
previews anew. Two begin partway into the attack, so they cannot identify
physical contact time. The uncensored F#2 attack is already close in spectral
centroid; that argues for a restrained change. We retained the bounded recoil
mapping instead of increasing its effect or fitting an arbitrary global EQ.

The [reference report](realism-reference-2026-09-08.md) records source pages,
licenses, preview hashes, complete analysis traces and primary physical
references. It also records the remaining gap: these recordings shed upper
harmonics and overall energy faster than Electry. This pass improves contact
behavior without claiming to have corrected that separate decay mismatch.

The three files were already part of an earlier source family used by this
project. They are descriptive development references, not untouched validation
data. Neither their compressed previews nor their unknown pick/hand setup
justify claiming fitted eight-string contact constants.

## Reproduction and auditions

The dedicated [renderer](../Experiments/Realism20260908/RenderRealism.cpp) and
[comparison tool](../Experiments/Realism20260908/AnalyzeRealism.py) freeze 24
scores: E1/F#1 chugs at 8/12/16 strokes per second, velocity contrasts,
open/fretted/late-muted releases, several hammer/pull intervals, and the three
reference pitches. Every score has both dry DI and the same Modern high-gain
chain. Output is float WAV, with event/parameter manifests and source hashes.

The ignored `build-realism-20260908/comparison/listening.html` supplies paired
auditions with one constant RMS-matching gain per complete file. Raw outputs
remain alongside it. This preserves accents within each phrase and prevents
an overall level boost from deciding the comparison. It does not substitute
for listening responses.

Build and run the production DSP/tool tests:

```sh
cmake -S . -B build-realism-20260908/current \
  -DCMAKE_BUILD_TYPE=Release -DELECTRY_BUILD_PLUGIN=OFF \
  -DELECTRY_BUILD_UNIVERSAL=OFF -DBUILD_TESTING=ON
cmake --build build-realism-20260908/current --parallel
ctest --test-dir build-realism-20260908/current --output-on-failure
```

New excitation tests cover eight physical strings, light/heavy gauges, four
sample rates, force-area conservation, finger isolation and repeat-pick
callback invariance. New contact tests cover decay-dependent releases,
distinct stopping hands, exact silence/reset, fret-local hammer geometry,
bent/interrupted hammer motion and callback invariance at 44.1–192 kHz.

The existing force observer now integrates the discrete release window rather
than assuming a fixed duration. The existing release-noise test uses a fretted
note so it measures a finger lift and verifies isolated half/full control
scaling; separate new tests cover the deliberately quieter open-string stop.
The rapid-Palm brightness test keeps its original 0.06 upper-band-fraction
minimum, but measures a 5–55 ms window ending before Note Off. Its former
30–80 ms window includes the release at 55 ms: disabling release noise alone
in the baseline lowers its fraction from 0.0759 to 0.0300. That would reward
the artificial release burst this work removes. The equal-length pre-release
window stays near 0.081 in both versions, including with release noise
disabled. The complete-window spectral report and original harmonicity limit
remain. These checks preserve physical/control invariants instead of treating
every changed waveform as a failure.

## Final validation results

Baseline is commit `85f6f851c4adece41acc118c9cdfbdf86dbb7b47`. Final auditions
were built from a frozen copy of the modified DSP; file hashes in
`build-realism-20260908/candidate-build-provenance.json` match the working tree.

- All **12 DSP/tool CTest targets passed** (45.27 s).
- All **four processor/artifact checks passed** (7.27 s): processor state and
  the built VST3, CLAP and Audio Unit. Standalone also built successfully.
- Both new suites passed under **AddressSanitizer and UndefinedBehaviorSanitizer**
  (2.82 s), including the interrupted pull-off toward an open string.
- Builds and host-artifact checks used native **macOS arm64**, AppleClang 21,
  Release and the project's pinned JUCE. This pass did not test another OS
  or the x86_64 slice.

All **48 dry/high-gain A/B pairs** are finite and unclipped. The maximum
candidate peak is −12.13 dBFS. Whole-file chug RMS changes by only −0.01 to
−0.05 dB; the late E1 Palm release's first 80 ms drops from −52.43 to
−76.09 dBFS through the fixed Modern chain. Open E1's short-release dry RMS
stays at approximately −41.51 dBFS. These are measured changes, not listener
ratings. Full per-score metrics are in the ignored comparison report.

Three interleaved repetitions per version produced identical WAV/manifest
hashes. The complete renderer, including Modern FX and WAV writes, took a
median **2.46267 s before / 2.46386 s after** (+0.048%, within the observed run
spread). That timing describes this workload and machine, not a universal
audio-callback overhead guarantee. The complete timing/source/binary receipt
is `build-realism-20260908/renderer-timing.json`.
