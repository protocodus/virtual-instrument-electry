# Strat DSP CPU Optimization Report — 2.6.2 (2026-11-23)

All optimizations in `Source/DSP/` preserve **100% bit-exact PCM identity (28 / 28 SHA-256 matches)** across all 7 factory Rack patches rendered at 44.1 kHz, 48 kHz, 96 kHz, and 192 kHz (`-std=c++17 -O2 -ffp-contract=off`).

## Optimizations Applied

1. **Hot-loop builtin / bit-op inlining (`DspCompatibility.h`, `StratString.cpp`, `StratPerformer.cpp`)**: added `ELECTRY_FORCE_INLINE` and replaced hot per-sample `std::abs` / `std::floor` calls with inline bit-manipulation helpers `scalarAbs` and `scalarFloor` (avoiding out-of-line `libm` calls under `-fno-builtin`).
2. **Hot-first member layout (`StratString.h`)**: moved the two 64 KB waveguide delay planes (`poles`, `top`) to the end of `StratString`, and moved per-sample filter states ahead of rail arrays inside `StratString::Plane`.
3. **Portable packed-struct 2-lane SIMD (`DspCompatibility.h`, `StratString.cpp`)**: introduced ABI-safe `Float2` (`packed, aligned(4)`) and `Double2` (`packed, aligned(8)`) vector wrappers and vectorized paired `poles` / `top` waveguide filtering (`readPickupPair`, `damp()`, `dampSpanPair`, dcMean/reflection, and loop/wrap/4-stage allpass filters) while keeping scalar operation order.
4. **Compact active circuit subspace (`StratCircuit.h`, `StratCircuit.cpp`)**: packed column-major contiguous `activePhiCol`, `activePrevCol`, and `activeCurrCol` matrices in `updateCoefficients()`, executed vertical 2-row `Double2` accumulation in `process()`, added an exact zero-state / zero-input `idle` fast-path, and added row-wise zero-skipping in `multiply()`.
5. **Oversampled jack mirror & idle bypass (`StratEngine.h`, `StratEngine.cpp`, `StratBridge.h`, `StratBridge.cpp`, `StratPerformer.cpp`)**: mirrored `jackHistory` (`2 * halfbandHistory`) with idle quiet bypass to eliminate 33 modulo masks per sample, precomputed `bendOffset` in `updateCoilGeometry()`, added `StratBridge::solveString(s)`, stopped single-string `setFret`/`setBend` calls from marking all 6 strings `bridgeMoved`, and fast-pathed exact-zero silent samples in `StratPerformer::render()`.
