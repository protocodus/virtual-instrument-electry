# E mechanical tap export/render draft

This single implementation is unexecuted and awaits root review. No source results, physical arrays or PCM have been opened, no numerical module imported, and no compiler/renderer called during preparation.

`export_render_draft_v1.py` gates all result access on fresh exact root/peer export authority plus independent **all96 mechanical** qualification of the IO-successor source root. It validates all96 primary rawtap arrays/clocks before any field is written. Export copies the callback-indexed float64 bits to the existing drivers; it performs no physical reconstruction, gain, interpolation, fade or timing adjustment. The unchanged C binaries retain the pickup/electrical chain and firstContact prime semantics.

`E-render-v1.json` uses the existing analysis contract:96rows with ID/scope/oldkey, receipt-relative PCM/metadata paths and hashes, and `all96_rendered_after_blind_gate:true`. Metadata must equal the original geometry/timeline/control capture except RMS/peak. The crop stays the native mono48k2s96000frames. The actual E source is described by its mechanics receipt; the old renderer force diagnostics remain visibly labelled legacy. Fq is the declared quasistatic source anchor, not an instantaneous contact force or calibrated real hand measurement.

Static dependencies already exist: frozen C source protocol/oldA identity/render receipts, Neck/Bridge external-tap driver source+binaries, the hook Source and Source6c83 identities. No rebuild is proposed. The missing dynamic prerequisite is a closed independently qualified all96 source run and its complete saved binding table. The draft also has no frozen implementationmanifest or root/peer executionauthorization. It must not be run yet.

Mechanical qualification precedes export/render. A separate combined all96mechanics+render rootseal and separate analysisauthorization follow independently verified PCM/metadata; requiring that combinedseal before rendering would be circular. The frozen analysis masks, gains, guards and E-only measured preContact background policy stay unchanged.

The pre-write space check requires the exact all96 float64field and96000framefloat32PCM bytes plus a fixed64MiB administrative metadata/log allowance. It creates no reserve layer and changes no physical parameter. Closed-source protocol identity/post-bindingPASS and pre-import NumPy root are mandatory.
